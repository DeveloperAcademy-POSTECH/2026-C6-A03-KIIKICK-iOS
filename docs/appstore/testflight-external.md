```
KIIKICK은 Apple Watch로 축구/풋살 경기 중 위치와 심박수를 기록하고,

```

   - "재생" 버튼을 누르면 10초 구간만 보이며 자동으로 움직이는지
   - "스탑"/"X" 버튼이 각각 의도대로 동작하는지(스탑=멈춤, X=전체 보기로 복귀)
