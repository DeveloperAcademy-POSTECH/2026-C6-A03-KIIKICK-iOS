# #49 히트맵·스프린트 맵

## 동작

- `WorkoutRecord.points`를 img_field 안쪽 운동장 영역에 정규화해 표시한다. 원본 GPS는 수정하지 않는다.
- 실제 미터 길이를 비교해 운동장의 긴 변을 화면 가로축에 대응시킨다. 북쪽이 위인 지리 좌표와 아래로 증가하는 화면 좌표의 차이를 보정해 거울상을 방지한다.
- 히트맵은 쿼터별 상대 밀도다. 80×52 격자에 위치 샘플 수를 집계하고 Gaussian kernel과 셀 크기 비례 블러로 연결한다. 렌더러와 해상도/스무딩 설정은 교체할 수 있다.
- 스프린트는 **21km/h 초과가 이어지는 구간 중 누적 GPS 경로 거리가 20m 이상**인 구간이다. A→B 이차 Bézier 곡선과 끝 접선을 따르는 화살촉으로 표시한다. 원본 경로를 보간한 선이 아닌 표시용 곡선이다.
- 공격 방향은 `(x, y) → (1-x, 1-y)`의 180° 회전이다. 분석 준비에서 포지션과 함께 SwiftData에 저장하고 상세·스프린트·타임라인의 맵과 이벤트에 반영한다.
- 히트맵·스프린트는 공통 페이지 컨트롤로 전환한다.

## Debug 위성사진

사용자 요청에 따라 Debug 빌드에 세 번째 위성사진 페이지를 유지한다. Release에는 포함하지 않는다.

- MKMapSnapshotter 위성사진 위에 원본 GPS 점(라임), 경로(파랑), 운동장 경계(흰색), 가로축(민트), 세로축(주황)을 표시한다.
- 페이지를 선택할 때만 로드하고 떠나면 취소한다. 실시간 Map/카메라 이벤트/MapProxy 갱신은 사용하지 않는다.
- 임시 운동장 선택 버튼은 제거했다. 기록에 연결된 Field를 사용한다.

## Design Gaps — 히트맵·스프린트

- 히트맵 색상은 Figma 데스크톱 Variables의 Color / Dark에서 직접 확인했다: dataviz/heatmap-low → blue/100 (#9CFFFD), mid → blue/300 (#0EEFFF), high → blue/500 (#21A3FF).
- 스프린트는 dataviz/sprintmap-low → lime/500 (#DFFF3F)를 사용한다. sprintmap-high → orange/500도 존재하지만 속도별 색상 전환 기준은 정하지 않았다.
- 🟡 정확한 곡률·선 치수·스무딩 반경은 미지정이라 교체 가능한 설정과 기존 화살표 치수를 사용한다.
- 🟡 페이지 컨트롤은 시스템 기본 표현으로 Figma 민트색 도트와 차이가 있다.

## 검증과 제약

- `bash scripts/validation/check-tracking-maps.sh`: 축 방향/길이/입력 순서, 밀도/스무딩/경계, 회전, 스프린트 속도·최소 거리·구간 분리, 설정 재개방과 GPS 보존을 확인한다.
- 합성 GPS 60,000개를 사용하는 별도 테스트 앱에서 반복 페이지 전환을 확인했다. 실기기에서 보고된 Freeze의 원인을 확정한 검증은 아니다. 마지막 사용자 확인에서는 재현되지 않았다.
- 공유 이미지 히트맵 연결과 타임라인 슬라이더 시간 필터링은 포함하지 않는다.
