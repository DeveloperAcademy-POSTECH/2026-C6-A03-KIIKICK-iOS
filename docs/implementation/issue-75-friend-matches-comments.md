## 친구 프로필과 분석

`GET /friends/{userId}/matches?status=COMPLETED`를 페이지별로 읽고, 경기 결과와 모든 쿼터 결과를 조회한다. 목록 API의 Swagger `Page`는 다른 API와 제네릭 이름이 겹쳐 정확하지 않으므로 서버 구현의 `MatchResponse` 목록 계약을 사용한다.

완료 상태이고, 쿼터 개수·경기 ID가 맞으며 모든 쿼터에 포지션과 업로드 운동 데이터가 있는 경기만 노출한다. 현재 앱은 ‘분석 보기’에서 workout-submissions를 호출하므로 이 제출 상태를 공개 기준으로 사용한다. 서버 목록 자체에는 별도의 `분석 보기/공개 여부` 필드가 없으므로, 다른 클라이언트에서 생성한 데이터까지 화면 진입 이력으로 구분하려면 서버의 공개 상태 계약이 추가되어야 한다.

프로필의 날짜 선택기는 현재 조회한 경기의 월을 사용한다. `경기 더 보기`로 이후 페이지와 과거 월을 읽는다. 미제출 경기만 있는 페이지는 다음 페이지까지 읽어 공개된 경기를 찾는다. 카드 선택 시 결과를 다시 조회하여 삭제·친구 관계 변경을 반영한다.

친구 상세는 기존 AnalysisDetailView를 재사용한다. 헤더에 닉네임과 날짜를 표시하고 공유·삭제·함께 뛴 친구 버튼을 숨긴다. 쿼터 선택에 따라 서버 지표·포지션·운동 시간·골/어시스트를 바꾼다. m/s는 km/h, m는 km로 변환한다. 계산 중·미제공 지표는 `—`로 표시한다. stats가 없으면 업로드 이벤트로 골/어시스트 개수를 산정하고, 이벤트도 없으면 임의로 0을 만들지 않는다.

## 경기장과 경로 제공 범위

경기장 이름과 좌표는 쿼터 결과의 `workout.field`에서 읽는다. `/venues`와 `/venues/{venueId}`는 ‘내 저장 경기장’ API로 주행 경로를 포함하지 않는다. 친구 결과에도 원본 GPS 경로는 없으며 원본 track-points API는 소유자 조회다. 친구의 로컬 기록을 만들거나 다른 사용자의 경로를 대신 표시하지 않는다. 맵은 기존 경기장 그림과 위치 경로 미제공 안내를 표시하고 타임라인 진입을 제공하지 않는다. 친구 히트맵·스프린트 지원에는 친구 경로 조회 API가 필요하다.

## 댓글

- 목록: GET `/matches/{matchId}/comments`, 페이지 추가 조회·중복 ID 제거.
- 작성: POST 같은 경로. 실제 서버 응답은 Swagger의 string과 달리 `201 { data: CommentResponse, meta }`이다.
- 본문: content만 전송하며 공백만 있는 입력과 Unicode 코드 포인트 1000자 초과를 막는다.
- 서버 성공 시에만 목록에 추가하고 입력을 비운다. 실패 시 입력과 동일 요청의 UUID Idempotency-Key를 유지한다.
- 작성자 UUID는 별도 공개 프로필로 조회하여 닉네임·사진을 표시한다. 페이지 내 중복 작성자는 한 번 조회한다. 프로필을 읽지 못하면 기본 이미지와 ‘사용자’로 표시한다.
- 댓글과 경기 조회가 403/404를 받으면 해당 화면의 이전 데이터를 제거한다.
- 삭제 API는 정의만 하며 삭제 버튼은 연결하지 않는다. 서버에 대댓글 계약이 없어 답글 버튼은 표시하지 않는다.
- 내 경기 상세도 같은 댓글 시트를 사용한다. 서버 matchId가 없는 Preview는 요청하지 않는다.

## 검증

- `scripts/validation/check-friend-matches.sh`: 실제 ProviderImpl·Endpoint·DTO·목록/댓글 모델에 가짜 URLSession을 주입한다. 응답 디코딩, 공개 필터, 페이지/쿼터 추가 조회, 계산 중 지표, 권한 상실, 작성자 조회, 댓글 중복·길이·실패 재시도·삭제 요청 계약을 확인한다.
- iOS/watchOS Simulator Debug·Release 빌드.
- 기존 온보딩·OVR·지도 검증 스크립트.
- 실계정 간 조회·댓글 작성은 실행하지 않았다. 테스트 JSON은 앱에 주입하지 않고 검증 스크립트에서만 사용한다.

## Design Gaps — 친구 분석·댓글

- 🟡 친구 상세의 별도 헤더 속성이 명시되지 않아 기존 navigationTitle에 닉네임·날짜를 함께 표시한다.
- 🟡 위치 경로 미제공·로딩·오류·빈 목록·추가 조회 상태는 기존 컴포넌트와 토큰으로 표시한다.
- 🟡 Figma 댓글 시트에는 답글이 있지만 서버는 단층 댓글만 제공한다. 답글 버튼을 숨긴다.
- 기존 프로필·카드·분석 상세·댓글 컴포넌트를 재사용한다. 새 디자인 토큰은 추가하지 않았다.
