# KIIKICK 개인정보 처리방침

KIIKICK(이하 ‘앱’)의 운영자는 축구·풋살 경기 기록과 분석 서비스를 제공하기 위해 개인정보를 처리합니다. 운영 주체는 [운영자 성명 또는 단체명 확정 필요]입니다.

## 1. 처리하는 개인정보 항목

| 구분 | 항목 |

|---| --- |

| 계정 및 인증 | 이메일 주소, 비밀번호, 사용자 식별자, 만 14세 이상 여부, 인증·세션 기록. 이메일 인증번호 발송 남용을 방지하기 위해 요청 IP 주소를 해시로 변환해 사용합니다. |

| 프로필 | 이용자가 입력한 닉네임 및 프로필 이미지 URL을 등록하는 경우 해당 URL |

| 경기 중 위치 | Apple Watch에서 측정한 위도·경도, 고도, 수평 위치 정확도, 이동 속도·방향, 측정 시각 |

| 건강·운동 | HealthKit의 심박수 및 측정 시각, 운동 시작·종료 시각, 활동 칼로리, 누적 이동 거리. 이용자가 별도로 설정하는 경우 운동 지표 계산에 사용하는 기준 최대 심박수 |

| 경기 및 운동장 | 경기 제목·일시, 쿼터, 골·어시스트, 대표 포지션, 저장한 운동장 이름·주소 및 경기와 운동장의 연결 정보. 운동장의 모서리나 골대 좌표를 사용하는 경우 앱이 기기에서 히트맵 표시를 위해 처리합니다. |

| 친구·앱 내 알림 기능 이용 시 | 친구 요청에 사용하는 서비스 내 식별자, 검색 공개 설정, 친구 요청·수락·차단 상태, 알림 및 읽음 상태 |

| 서비스 이용 및 문의 | 동의 항목·버전·동의 여부·기록 시각, 서비스 요청 시각·응답 상태·응답 시간·요청 식별자, 문의 시 이용자가 제공한 연락처 및 문의 내용 |

계정은 이메일 인증과 비밀번호를 사용합니다. TestFlight는 만 14세 이상을 대상으로 하며, 이메일 인증 요청 전에 만 14세 이상인지 확인합니다. 생년월일은 수집하지 않습니다. 위치 및 건강정보는 경기 측정 중 Apple Watch에서 수집합니다.

## 2. 처리 목적

- 이메일 인증, 회원가입, 본인 확인 및 계정 관리
- 경기·쿼터와 운동장 기록의 저장 및 조회
- 이동 거리, 평균·최고 속도, 평균·최고 심박수, 운동 부하 등 운동 지표 계산과 경기별·기간별 통계 제공
- 경기 경로를 운동장 좌표계에 맞춰 표시하는 히트맵, 타임라인 구간 재생, 심박 그래프 제공
- 친구 검색·요청·차단 및 앱 내 알림 제공
- 문의 응대, 인증 요청 남용 방지, 장애 감지 및 오류 원인 분석

## 3. 원본과 분석 결과의 처리 방식

Apple Watch에서 기록한 운동 데이터는 iPhone으로 전송됩니다. iPhone 앱은 운동 시작·종료 시각과 이용자가 동의한 항목만 서버에 전송합니다. 운동장의 모서리·골대 좌표는 기기에 저장하며 서버에는 운동장 이름·주소와 경기 연결 정보만 저장합니다.

- GPS에만 동의하면 위치 샘플을 전송해 경로와 GPS 기반 거리·속도 등을 제공합니다.

- 건강정보에만 동의하면 심박 샘플과 HealthKit에서 가져온 활동 칼로리·이동 거리 등 운동 정보를 전송해 심박 그래프와 심박 기반 분석을 제공합니다.

- 두 정보가 모두 필요한 지표는 양쪽에 동의하고 계산에 필요한 데이터가 있을 때에만 제공합니다. 어느 쪽에도 동의하지 않으면 센서 데이터를 수집하거나 서버에 보내지 않으며, 직접 입력한 경기 기록은 저장할 수 있습니다.

서버는 쿼터에 연결된 운동 원본으로 거리·속도, 가속·감속·방향 전환 횟수, 평균·최고 심박수, 운동 부하(Edwards TRIMP) 등을 자동 계산하고 요약 결과를 별도로 저장합니다. 지표 산출에 사람이 개입하지 않습니다. GPS와 심박 원본은 요약이 만들어진 후에도 경로·심박 조회와 운동 지표 재계산에 사용할 수 있도록 서버에 보관합니다.

## 4. 보유 기간 및 파기

| 구분 | 보유 기간 |

| --- | --- |

| GPS·건강정보 원본, 운동 세션 및 해당 정보에서 산출한 운동 요약·통계 | 해당 경기 기록의 삭제, 해당 항목의 수집·이용 동의 철회 또는 회원 탈퇴 중 먼저 발생하는 때까지. 동의를 일부 철회하면 철회한 항목의 원본과 그 원본에 의존하는 요약·통계를 파기합니다. 남은 동의 범위의 데이터로 계산할 수 있는 지표는 다시 산출합니다. |

| 수동 경기 기록 | 해당 경기 기록 삭제 또는 회원 탈퇴 중 먼저 발생하는 때까지. 건강정보나 GPS 동의를 철회한 뒤에도 직접 입력한 경기 정보, 골·어시스트 및 포지션은 유지합니다. |

| 저장 운동장 | 운동장 삭제 또는 회원 탈퇴 중 먼저 발생하는 때까지. 이미 저장한 경기의 운동장 이름·주소 사본은 해당 경기 기록과 함께 보유합니다. |

| 계정·프로필 및 동의 이력 | 회원 탈퇴 시까지 |

| 친구 관계 및 차단 | 관계 해제, 차단 해제 등 각 처리 목적이 끝나는 때 또는 회원 탈퇴 중 먼저 발생하는 때까지 |

| 앱 알림 기록 | 생성일부터 최대 90일 또는 회원 탈퇴 중 먼저 발생하는 때까지 |

| 이메일 인증번호·가입 토큰과 관련 인증 시도 기록 | 인증 절차 완료 또는 만료 후 최대 24시간. 발송 제한용 이메일 주소와 IP 해시 기록은 마지막 발송 시도부터 최대 24시간. |

| 로그인 세션 및 갱신 토큰 해시 | 로그아웃·세션 폐기·회원 탈퇴 또는 최초 발급 후 90일 중 먼저 발생하는 때까지 |

| 일반 장애 진단 로그 | 생성일부터 14일 |

| 문의 기록 | 문의 처리 완료일부터 30일 |

| 민감정보 처리 시스템에 대한 운영 담당자 접속기록 | 생성일부터 2년. 개인정보 안전성 확보조치 기준에 따라 보관합니다. |

| 장애 복구용 백업 | 생성일부터 최대 7일. 삭제 대상 정보가 포함된 백업은 아래 파기 절차를 따릅니다. |

회원 탈퇴는 앱의 마이페이지 → 계정 관리 → 회원 탈퇴에서 요청할 수 있습니다. 탈퇴 접수 즉시 계정 접근과 세션을 차단하고, 운영 서버의 계정·운동 기록 등 관련 정보를 지체 없이 파기합니다. 탈퇴·기록 삭제·동의 철회에 따른 파기 작업은 접수일부터 최대 5일 이내에 완료하며, 이용자에게 처리 결과를 안내합니다.

전자 기록은 복구할 수 없는 방식으로 파기합니다. 삭제 대상이 들어 있는 백업에서도 해당 정보를 파기하며, 개별 삭제가 어려운 백업은 삭제 대상이 제외된 백업으로 교체한 뒤 기존 사본을 파기합니다. 복구 시에도 이미 삭제된 기록이 다시 노출되지 않도록 합니다.

위 기간이 지나거나 처리 목적을 달성한 개인정보는 지체 없이 파기합니다. 관계 법령에 따라 계속 보관해야 하는 기록은 해당 법정 기간 동안 서비스 데이터와 분리해 보관한 뒤 파기합니다. 앱이 기기에 저장한 기록 사본은 앱에서 해당 기록을 삭제하거나 탈퇴 처리가 기기에 반영될 때 삭제합니다. Apple 건강 앱에 별도로 저장된 운동 기록은 이용자가 건강 앱에서 관리할 수 있습니다.

## 5. 제3자 제공

앱은 건강정보 및 위치정보를 광고, 마케팅, 데이터 판매 목적으로 이용하거나 제공하지 않습니다. TestFlight에서는 GPS 경로, 심박 원본, 운동 지표와 경기 분석 결과를 본인에게만 보여주며 친구 비교 기능은 제공하지 않습니다.

친구 검색 공개는 기본적으로 꺼져 있습니다. 이용자가 별도로 동의해 공개를 켜면 로그인한 이용자의 검색 결과에 닉네임과 친구 요청 상태가 표시됩니다. 친구 요청에는 서비스 내 식별자를 사용합니다. 요청을 보내거나 받으면 상대방에게 닉네임과 요청 상태를 표시합니다. 공개를 끄면 새 검색 결과에서 즉시 제외되며, 차단하면 해당 이용자와 서로 검색하거나 요청할 수 없습니다. 계정 이메일과 프로필 이미지는 친구 검색이나 요청 화면에 표시하지 않습니다.

이 외에 개인정보를 제3자에게 제공하는 경우, 이용자에게 별도로 동의를 받거나 관계 법령에 따른 근거가 있을 때에 한해 제공합니다.

## 7. 국외 이전

TestFlight 운영 기준은 앱 서버·DB·백업·로그·문의 기록을 AWS 서울 리전에 두고, 개인정보를 국외로 복제하거나 국외에서 조회하지 않도록 하는 것입니다. 인증 이메일 발송에는 서울 리전의 Amazon SES를 사용합니다.

[공개 전 확인] 실제 리소스와 재해 복구 설정, 수탁·재위탁 및 국외 지원 접근, 인증 메일 전달 과정까지 확인한 뒤 국외 이전 여부를 확정합니다. 국외 이전이 필요한 경우 이전에 앞서 법적 근거, 항목, 국가, 시기·방법, 이전받는 자와 연락처, 목적과 보유·이용 기간, 거부 방법·절차 및 영향을 안내합니다.

## 8. 건강정보에 대한 별도 동의

앱은 건강정보를 처음 수집하기 전에 건강정보의 수집·이용 및 서버 저장에 대한 동의를 별도로 받습니다. 경기 중 GPS 수집·이용 동의와 Apple 기기의 위치·HealthKit 권한은 각각 구분합니다.

- 처리 항목은 심박수와 측정 시각, 운동 시작·종료 시각, 활동 칼로리, 누적 이동 거리 및 이용자가 설정한 기준 최대 심박수입니다.

- 처리 목적은 경기 중 운동 기록, 심박 그래프, 운동 부하 등 본인의 경기 분석을 제공하는 것입니다.

- 보유 기간은 제4항을 따릅니다.

- 동의 거부 시 심박·운동 분석 기능이 제한됩니다. 위치정보 동의를 거부하면 이동 경로, 히트맵, 구간 재생 기능이 제한됩니다. 각각 동의한 항목만 수집하며, 계정 관리와 수동 경기 기록은 계속 이용할 수 있습니다.

동의 내역에는 이용자 식별자, 동의 항목, 안내문 버전, 선택 결과와 시각을 기록합니다. 서버는 유효한 동의가 있는 항목만 업로드받습니다. 마이페이지 → 개인정보 설정에서 각각 철회할 수 있습니다. 철회하면 해당 항목의 신규 수집·업로드와 서버 분석을 중단하고, 기존 데이터와 영향을 받은 분석 결과는 제4항에 따라 삭제하거나 남은 데이터로 다시 계산합니다.

## 9. 이용자의 권리와 행사 방법

이용자와 법정대리인은 개인정보 열람·정정·삭제, 처리정지 및 동의 철회를 요구할 수 있습니다. 앱의 마이페이지 → 문의하기 → 개인정보 요청 또는 [로그인 없이 접수할 수 있는 공식 문의 양식 URL]을 통해 요청할 수 있습니다. 접수에는 회신 연락처, 요청 유형과 필요한 설명만 받습니다.

운영자는 본인 또는 정당한 대리인인지 확인한 뒤 지체 없이 처리합니다. 열람·정정·삭제 및 처리정지 요청에는 접수일부터 10일 이내에 결과를 안내하고, 삭제 대상은 제4항의 더 짧은 파기 기한을 적용합니다. 요청을 제한하거나 거절하는 경우에는 사유와 이의제기 방법을 안내합니다.

기기 설정에서 위치·HealthKit 권한을 변경할 수 있습니다. 서비스의 수집·이용 동의는 제8항의 개인정보 설정 또는 위 접수 경로에서 철회할 수 있습니다. 서버 기록의 삭제는 위 접수 경로에서도 요청할 수 있습니다.

## 10. 안전성 확보조치

- 앱과 서버는 HTTPS로 통신하고, 서버와 DB는 TLS로 연결합니다.

- 비밀번호와 세션 갱신 토큰은 해시로 저장합니다. 운영 DB가 저장되는 디스크와 백업은 암호화하고, 암호화 키는 AWS KMS에서 별도 권한으로 관리합니다.

- 서버는 업로드·조회·삭제 요청마다 이용자의 계정과 해당 기록의 소유권을 확인합니다. 서버에 저장하는 건강·위치정보는 동의 상태도 확인합니다.

- 관리자는 개인 계정과 다중 인증을 사용합니다. 승인받은 담당자에게 필요한 기간과 범위로 권한을 부여하며, 업무 변경이나 종료 시 회수합니다.

- 운영자 접속기록은 접근 권한을 제한한 별도 저장소에 2년간 보관하고 월 1회 점검합니다. 일반 진단 로그에는 GPS·심박 원본, 비밀번호·인증번호·토큰 및 요청 본문을 기록하지 않습니다.
